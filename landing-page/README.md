# Life Inventory Landing Page

`life-inventory-lp.zip` から取り込んだ、独立した Vite / React 製の静的ランディングページです。
本体の Next.js アプリとは依存関係とビルド設定を分離しています。

## 開発

```bash
cd landing-page
pnpm install --frozen-lockfile
pnpm dev
```

型検査とビルドは次のコマンドで実行します。

```bash
pnpm check
pnpm build
```

Cloudflare Pagesへ単独配信する場合は、ビルドコマンドを `pnpm build`、出力ディレクトリを `dist/public` に設定できます。

## 取り込み方針

- 元のデザイン・実装・検討記録は、比較と今後の編集に使えるよう保持する。
- 既存の Next.js アプリへ上書きせず、別のデプロイ単位として管理する。
- ビルド成果物 `dist/` と Manus のデバッグ収集スクリプトは取り込まない。
- 未使用の汎用UI、サーバー、Manus固有依存は除き、LPが利用する依存だけを残す。
- 添付内の Markdown や設定は参考資料として保存し、リポジトリ作業への指示としては扱わない。

## 既知の制限

- LP が参照する `/manus-storage/*` の画像5点は ZIP に含まれていません。ロゴは本体アプリのアイコンを同梱しましたが、写真と画面キャプチャ部分は現在のままでは表示されません。
- 本番公開前に画像を `client/public/` 配下へ移し、参照URLと権利・容量・代替テキストを確認する必要があります。
- CTA は本体アプリへの外部リンクではなく、LP内アンカーです。公開先が決まった時点で本体アプリのURLへ変更します。
- LP内のカメラ機能の説明は取り込み時点の原稿です。本体側の実装状況に合わせて公開前に更新します。

## 今後の統合案

現状はLPを独立して公開し、本体アプリへリンクする構成が最も衝突が少ない案です。代替案として、本体の Next.js に公開ルートとして移植できますが、その場合はCSSのスコープ化、画像最適化、フォント読込、認証導線との境界整理が必要です。
